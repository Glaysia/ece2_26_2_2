## 1. 작성 및 제출 원칙

실험은 팀별로 수행하되, 보고서는 개인별로 작성하여 제출한다.

| 구분 | 제출 요건 |
|---|---|
| 표지 | 작성자의 이름과 학번을 포함한다. |
| 파일 형식 | PDF로 제출한다. |
| 본문 편집 | 지면을 좌우로 나누는 2단 구성을 사용한다. |
| 첨부 자료 | 핵심 소스코드 일부, 시뮬레이션 결과 이미지, 실제 동작 시연 사진을 포함한다. |
| 저장소 정보 | GitHub 저장소 주소, 제출 버전의 태그(tag), 커밋 해시(commit hash)를 명시한다. |
| 자료 접근 | 제출한 링크에서 해당 버전의 전체 소스코드와 작동 영상을 확인할 수 있어야 한다. |
| 인용 및 참고문헌 | 허용된 출처를 1개 이상 인용하고, 본문의 인용 위치에 출처를 표시하며 보고서 말미에 참고문헌을 기재한다. |

### 인용 및 참고문헌 기준

- 위키: 인용 출처로 인정하지 않는다.
- GitHub 저장소: 스타(star) 10개 이상인 저장소만 인정한다. 저장소 주소와 참조한 버전 또는 커밋 해시, 확인일을 기재한다.
- 교과서: 인용 가능하다. 저자, 제목, 판본 및 출판 정보를 기재한다.
- 논문: 인용 가능하다. 저자, 제목, 학술지 또는 학회명, 연도 및 DOI 또는 URL을 기재한다.
- 일반 도서: ISBN이 있는 책만 인정한다. 저자, 제목, 출판 정보 및 ISBN을 기재한다.
- 직접 인용한 문장은 따옴표 또는 인용문 형식으로 구분하고, 해당 출처와 쪽수(있는 경우)를 표시한다. 내용을 요약하거나 바꾸어 서술한 경우에도 출처를 표시한다.
- 본문 인용 표시(예: [1])와 참고문헌 목록을 서로 대응시킨다.
