# 전자전기컴퓨터설계실험Ⅱ 수업계획서

## 1. 교과목 개요

**교과목명:** 전자전기컴퓨터설계실험Ⅱ  
**수업시간:** 매주 월요일 14:00–18:00  
**강의실:** 19-213  
**수강인원:** 20명  
**팀 구성:** 2인 1조, 총 10개 조  
**주요 실습장비:**  
- Xilinx Spartan-7 XC7S75 FPGA 교육용 보드
- STM32 NUCLEO-G474RE, 팀당 1대
- 오실로스코프, 함수발생기, 전원공급기 등

본 과목은 디지털논리설계 및 마이크로프로세서 관련 선수과목에서 습득한 이론을 바탕으로, FPGA와 MCU를 이용하여 실제 디지털 시스템을 설계·구현·검증하는 실험 및 프로젝트 과목이다.

전반부에서는 FPGA와 STM32의 기본 개발 및 실험을 각각 수행하고, 이후 FPGA와 MCU를 함께 사용하는 통합 시스템 설계 프로젝트를 진행한다.

단순한 소프트웨어 작성 또는 HDL 문법 학습에 그치지 않고,

**설계 → 시뮬레이션 → 구현 → 계측 → 디버깅 → 시스템 통합**

의 전체 설계 과정을 경험하는 것을 목표로 한다.

---

# 2. 교과목 목표

수강생은 본 과목을 통해 다음 능력을 습득한다.

1. Verilog HDL을 이용하여 조합회로 및 순차회로를 설계할 수 있다.
2. Testbench 및 waveform을 이용하여 디지털 회로의 동작을 검증할 수 있다.
3. FPGA에 설계한 논리회로를 합성하고 실제 하드웨어에서 검증할 수 있다.
4. C 언어를 이용하여 STM32 MCU의 주변장치를 제어할 수 있다.
5. GPIO, Timer, PWM, Interrupt, UART, SPI 등 기본 MCU peripheral을 사용할 수 있다.
6. FPGA와 MCU 간 디지털 통신 인터페이스를 설계할 수 있다.
7. FPGA와 MCU의 역할을 적절히 분할하여 하나의 임베디드 디지털 시스템을 구성할 수 있다.
8. 오실로스코프 등 계측기를 이용하여 실제 디지털 신호를 관찰하고 문제를 진단할 수 있다.
9. 팀 단위로 시스템을 설계하고 구현하여 최종 프로젝트를 완성할 수 있다.

---

# 3. 수업 운영 방식

본 과목은 **사전 설계 및 실험실 검증 중심**으로 운영한다.

수강생은 가능한 한 실험실 수업 전에 해당 주차의

- 소스코드 작성
- 시뮬레이션
- 기본적인 기능 검증

을 완료하는 것을 권장한다.

매주 4시간의 실험실 수업시간은 주로

- 실제 FPGA/MCU 보드 구현
- 오실로스코프를 이용한 신호 확인
- 하드웨어 문제 해결
- 코드 및 회로 디버깅
- 조교 확인

에 활용한다.

사전 시뮬레이션 결과가 정상이고 실제 보드에서도 요구 기능이 정상적으로 동작하는 경우, 실험 확인 후 개별 실험을 종료할 수 있다.

단순히 정해진 4시간 동안 실험실에 머무르는 것보다 **주어진 설계 목표를 정확히 구현하고 검증하는 것**을 우선한다.

# 4. 개발 환경

## FPGA

**Hardware**
- Xilinx Spartan-7 XC7S75

**Development**
- Verilog/SystemVerilog
- VS Code 기반 코드 작성 및 빠른 simulation

# 7. FPGA 실험 세부 구성

아래 세 실험을 3주 동안 진행하고, 추가 0.5주에는 실험 보완 및 정리를 진행한다.

## FPGA 실험 1 — Digital Logic & Simulation

목표:

- HDL 기반 digital design workflow 이해
- 실제 보드 구현 이전에 simulation을 통한 검증 습관 형성

주요 내용:

- Verilog module
- combinational logic
- parameter
- testbench
- waveform
- FPGA pin assignment
- synthesis / implementation / programming

학생은 실험 전에 simulation 결과를 준비하고, 실험실에서는 FPGA board에서 실제 동작을 확인한다.

---

## FPGA 실험 2 — Sequential Logic & FSM

주요 내용:

- flip-flop / register
- synchronous counter
- clock divider 또는 clock enable
- button debounce
- finite-state machine
- PWM

단순 결과 확인뿐 아니라 waveform을 이용해 clock 단위의 동작을 설명할 수 있어야 한다.

---

## FPGA 실험 3 — Digital Interface

주요 내용:

- UART TX/RX 또는 이에 준하는 digital interface
- serializer / deserializer
- baud timing
- FSM
- data register

최종적으로 PC 또는 외부 장치와 실제 데이터를 송수신한다.

이 실험의 결과는 이후 STM32-FPGA 통합 실험에서 재사용할 수 있도록 구성한다.

# 12. 생성형 AI 사용

본 과목에서는 ChatGPT, Codex 및 기타 생성형 AI 도구의 사용을 원칙적으로 허용한다.

현대적인 개발환경에서 AI 도구를 활용하는 능력 역시 실제 engineering workflow의 일부로 본다.

다만 AI가 생성한 HDL 또는 C 코드를 제출하는 것만으로 해당 설계를 이해했다고 인정하지 않는다.

학생은 자신이 제출한 모든 코드에 대해

- module 또는 function의 역할
- 주요 signal의 의미
- FSM의 상태 전이
- timing
- peripheral 설정
- 통신 protocol
- 실제 측정 결과

를 설명할 수 있어야 한다.

필요한 경우 실험 확인 과정에서 코드 또는 waveform에 대한 간단한 구두 질문을 실시할 수 있다.

AI가 생성한 코드에 오류가 있는 경우에도 제출 및 설계에 대한 책임은 해당 팀에 있다.

- 검증 방법

를 함께 평가한다.

# 15. 프로젝트 평가 시 중요 원칙

화려하지만 동작이 불완전한 프로젝트보다, 범위가 작더라도 설계 목표가 명확하고 안정적으로 동작하며 충분히 검증된 프로젝트를 높게 평가한다.

특히 다음 항목을 중요하게 평가한다.

- 요구사항을 실제로 만족하는가
- Simulation 결과와 hardware 결과가 일치하는가
- 학생이 설계한 구조를 설명할 수 있는가
- FPGA를 사용한 이유가 명확한가
- STM32를 사용한 이유가 명확한가
- subsystem 간 interface가 체계적으로 설계되었는가
- 계측 또는 객관적인 방법으로 동작을 검증하였는가

# 16. 실험장비 관리

STM32 NUCLEO-G474RE는 팀별로 학기 초 1대씩 지급하며 프로젝트 종료 시 반납한다.

학생은 지급받은 장비를 학기 동안 직접 관리한다.

FPGA board 및 실험실 계측장비 사용 시 전원 및 I/O voltage를 확인한 후 연결하여야 한다.

보드 파손 가능성이 있는 회로 연결은 전원을 인가하기 전에 반드시 확인한다.

---

# 17. 수업의 최종 목표
