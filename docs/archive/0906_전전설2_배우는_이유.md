# 이번 과목의 내용을 활용하는 직무: 전전컴 5개 분야

- 반도체·회로·디스플레이
    - 디지털 회로 설계·검증: 논리 설계·파형 검증 (HDL, C/C++)
    - 반도체 테스트·평가: 입출력 시험·측정 (Python, C/C++)
    - 장비·디스플레이 제어 펌웨어: 입출력·타이머·통신 (C/C++)
- 전기·제어·로봇
    - 전력변환·모터 제어 펌웨어: ADC·PWM·인터럽트 (C/C++)
    - 로봇 제어 펌웨어: 센서·통신·상태 제어 (C/C++)
    - BMS 펌웨어: 측정·조건 판단·보호 상태 제어 (C/C++)
- 컴퓨터·디지털시스템
    - XPU·SoC·네트워크 칩 설계·검증: 레지스터·FSM·시뮬레이션 (HDL, C/C++)
    - FPGA 개발: 논리 설계·합성·보드 검증 (HDL, C/C++)
    - 펌웨어·드라이버 개발: 레지스터·주변장치·인터럽트 (C/C++)
- 통신·신호처리
    - 모뎀·신호처리 회로 구현: 데이터 경로·타이밍 검증 (HDL, C/C++)
    - 통신장치 펌웨어: 송수신·데이터 형식·상태 제어 (C/C++)
- 전파·광·양자
    - 레이더·RF·광학 장비 제어: 타이밍·통신·계측 (Python, C/C++, HDL)
    - 광송수신 모듈 펌웨어: 장치 설정·상태 감시 (C/C++)
    - 양자 제어 전자장치: 펄스·시퀀스·측정 인터페이스 (HDL, C/C++, Python)
