# LAB3 PDF 화면 검수

검수일: 2026-09-21.

- PDF 9개, 총 265쪽을 Poppler로 렌더링하고 페이지별 축소판으로 배치·글자·코드·표·쪽번호를 확인했다.
- 실제 VS Code·Vivado 캡처 42장이 해당 실험의 페이지에 들어 있고 제목·푸터와 겹치거나 잘리지 않는 것을 확인했다. 원본 창 캡처는 저장 당시 별도로 확인했다.
- UART XSim 캡처 페이지는 1200픽셀 렌더링으로 추가 확인했다.
- 검수 중 발견한 옛 스텝모터·시계 파라미터/포트 이름과 목차 안내를 실제 소스에 맞췄다. 수정된 6개 페이지를 다시 렌더링하여 확인했다.
- 최종 XeLaTeX 로그에 Overfull 또는 빌드 오류가 없다. 작은 수식 글꼴과 D2Coding 이탤릭은 대체 글꼴 경고가 있으나 렌더링에서 깨진 글자는 발견하지 않았다.
- 자동 PDF 검사와 ZIP 새 폴더 추출 후 바이트 일치 검사를 통과했다. PDF별 해시는 `pdf-validation.json`에 기록한다.

실제 보드 프로그래밍·실물 동작 관찰은 수행하지 않았다.
