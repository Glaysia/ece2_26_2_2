\begin{frame}{FPGA: 디지털 회로 구성}
\begin{itemize}
\item Verilog HDL로 회로의 동작과 연결을 기술한다.
\item 도구가 설계를 FPGA의 논리·저장·연결 자원에 구현한다.
\item 여러 회로가 같은 시간에 동작할 수 있다.
\item 클록에 따라 어떤 값이 갱신되는지 설계한다.
\end{itemize}
\vspace{0.4cm}
\textbf{확인할 것}: 어떤 회로가 연결되어 있고, 언제 값이 바뀌는가?
\end{frame}

\begin{frame}{C와 Verilog를 읽는 관점}
\begin{itemize}
\item C 프로그램은 CPU가 실행할 명령어로 컴파일된다.
\item 합성용 Verilog는 구현할 회로를 기술한다.
\item Verilog의 \texttt{if}는 선택 논리나 갱신 조건 등을 표현한다.
\item 고정 횟수 \texttt{for}가 반복 횟수만큼의 클록을 뜻하지는 않는다.
\item 여러 클록에 걸친 동작은 상태와 레지스터의 갱신으로 설계한다.
\end{itemize}
\vspace{0.2cm}
테스트벤치는 시뮬레이터에서 실행하는 검증 코드로 구분합니다.
\end{frame}

\begin{frame}{MCU: CPU와 주변장치 활용}
\begin{itemize}
\item STM32는 CPU, 메모리와 주변장치를 갖춘 마이크로컨트롤러다.
\item C 프로그램으로 입력을 읽고 동작을 결정한다.
\item GPIO, 타이머, 인터럽트와 통신장치를 설정한다.
\item 타이머와 통신장치는 설정 후 하드웨어에서 동작할 수 있다.
\end{itemize}
\vspace{0.4cm}
\textbf{확인할 것}: 어떤 기능을 설정하고, 프로그램과 어떻게 연결하는가?
\end{frame}

 & \textbf{FPGA} & \textbf{STM32} \\

값 저장 & 레지스터·갱신 조건 설계 & 변수·메모리·레지스터 사용 \\

\end{tabular}
\end{frame}

\begin{frame}{통합 예제: 밝기와 동작 모드 제어}
\begin{enumerate}
\item STM32가 사용자 명령을 받아 설정값을 정한다.
\item 통신으로 설정값을 FPGA에 전달한다.
\item FPGA가 설정값에 따라 PWM 신호를 만든다.
\item 출력 주기와 duty를 측정해 설정값과 비교한다.
\end{enumerate}
\vspace{0.4cm}
단순 PWM은 MCU만으로도 구현할 수 있습니다.\\
이 예제에서는 역할 분담과 장치 간 연결을 연습합니다.
\end{frame}

\item 일반 도서: ISBN이 있는 책, 서지 정보와 ISBN
\item GitHub: 스타 10개 이상인 저장소, 주소·버전·확인일
\item 위키는 인용 출처로 인정하지 않는다.
\end{itemize}
\end{frame}
