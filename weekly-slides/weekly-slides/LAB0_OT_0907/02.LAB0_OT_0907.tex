\begin{frame}{UART · 컴퓨터와 FPGA를 연결하기}
\textbf{PC 터미널 → USB--UART → FPGA 수신 → 송신 → PC 표시}
\vspace{0.25cm}
\begin{itemize}
\item PC와 FPGA의 보레이트·데이터 비트·패리티·정지 비트를 맞춘다.
\item 한 바이트를 전송하고 같은 값이 돌아오는지 확인한다.
\item 터미널의 로컬 에코를 끄고, FPGA가 돌려준 결과를 확인한다.
\item 연속 전송과 리셋 후 재전송도 확인한다.
