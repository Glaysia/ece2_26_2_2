## 원본과 편집 범위

`00.legacy_hdl.tex`가 본문·목차·표·그림의 SSOT다. 기존 교육자료를 재구성한 교재이며 개인 저자로 표기하지 않는다. 출처는 TeX 안에 보존한다.

- 목차 항목은 TeX의 section/subsection에서 관리한다.
- 설명·진리표·핀 참고표는 LaTeX, 설명용 도식은 TikZ에서 수정한다.
- 구형 장비 핀표를 현재 보드용 XDC로 사용하지 않는다.
- 실제 시뮬레이션 캡처와 설명용 그림을 구분한다.
- 글꼴·로고는 공용 `weekly-slides/assets/`를 참조한다.

## 현재 재빌드 제한

기존 PDF는 남아 있으나, `1f4e597`에서 다음 프로젝트가 삭제되었다.

- `example/fpga_projects_hdl/example_project_hdl/`
- `example/fpga_projects_hdl/legacy_all_hdl/`

TeX는 두 번째 프로젝트의 `captures/`에 있던 CodeSnap PNG를 여전히 참조한다. 따라서 **현재 체크아웃을 clone하는 것만으로는 이 교재를 재빌드할 수 없다.** 소스·캡처·VCD가 현재 제공된다고 안내하지 않는다.

재빌드하려면 필요한 캡처를 별도로 복구해 교재 리소스로 관리하거나, TeX의 코드 이미지 부분을 대체해야 한다. 이번 문서 정리에서는 삭제한 프로젝트를 복원하지 않았다.

리소스 문제를 해결한 뒤 이 폴더에서 실행한다.

```powershell
xelatex -interaction=nonstopmode -halt-on-error 00.legacy_hdl.tex
xelatex -interaction=nonstopmode -halt-on-error 00.legacy_hdl.tex
```

코드 이미지를 바꾸면 파일명, 줄 범위, trim/clip, 페이지 배치도 확인한다. TeX 빌드가 코드 이미지를 자동으로 재생성하지는 않는다.
