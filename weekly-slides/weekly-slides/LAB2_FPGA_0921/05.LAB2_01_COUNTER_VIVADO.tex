\begin{frame}{파형을 읽는 순서}
\small
\begin{enumerate}
\item clk 상승 에지 직후 value가 바뀌는지 본다.
\item down=0의 증가 구간과 down=1의 감소 구간을 비교한다.
\item enable=0 구간에서 value가 유지되는지 확대한다.
\item 마지막 rst=1 구간과 356 ns 종료를 확대해 확인한다.
\item 신호 이름·시간축·입력·출력이 함께 보이게 캡처한다.
\end{enumerate}
\end{frame}

\begin{frame}[label=reports]{실험 전 레포트}
\small
\begin{enumerate}
\item RTL과 테스트벤치가 맡은 역할을 설명한다.
\item 초기화·증가·감소·순환·유지의 예상 결과를 표로 적는다.
\item 자신이 실행한 PASS 로그와 파형을 넣고 각 구간을 설명한다.
\item Python 경로 등 자신이 고친 설정과 발생한 오류를 적는다.
\item XDC는 작성했지만 이번 기능 시뮬레이션에 사용되지 않았음을 구분한다.
\end{enumerate}
\end{frame}

\begin{frame}{합성 → 구현 → bit 생성}
\small
\begin{enumerate}
\item 합성은 RTL을 FPGA 논리 소자로 변환한다.
\item 구현은 소자를 배치하고 신호를 배선한다.
\item 마지막으로 FPGA에 기록할 .bit 파일을 생성한다.
\item 우상단 진행 상태와 하단 Design Runs를 확인하며 기다린다.
\item 실패하면 Messages의 첫 Error를 확인한다. 완료 전 같은 작업을 다시 실행하지 않는다.
\end{enumerate}
\end{frame}

\begin{frame}{보드에서 실행하는 순서}
\small
\begin{enumerate}
\item Combo II-DLD S75의 전원·JTAG 연결을 확인하고 메인 클록을 1 kHz로 맞춘다.
\item Vivado 왼쪽 Open Hardware Manager를 누른다.
\item Open Target → Auto Connect를 선택한다.
\item 검색된 xc7s75 장치를 우클릭 → Program Device.
\item Bitstream file에서 lab2\_counter.bit 선택 → Program.
\end{enumerate}
\end{frame}

\begin{frame}{기록 후 동작 확인}
\small
\begin{enumerate}
\item 리셋 입력(K4)을 활성화해 하위 LED 4개가 0인지 확인한다.
\item 방향 입력 sw[0](DIPSW8)을 0으로 두고 N8 버튼을 눌렀다 놓는다. 한 번에 1씩 증가해야 한다.
\item 15에서 한 번 더 누르면 0으로 순환하는지 본다.
\item sw[0]=1로 바꾸고 버튼을 눌러 감소와 0→15 순환을 확인한다.
\item 버튼을 길게 누르면 연속 증가하지 않고, 놓았다 다시 눌러야 다음 값으로 바뀌는지 확인한다.
\end{enumerate}
\end{frame}
