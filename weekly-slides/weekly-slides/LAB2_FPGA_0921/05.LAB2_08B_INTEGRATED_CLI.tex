\end{frame}

\begin{frame}{빈 파일에서 시작}
\small
\begin{enumerate}
\item src/design.v를 우클릭 → Rename. 첫 RTL 파일명으로 바꾼다.
\item 추가 RTL은 src를 우클릭 → New File로 만든다.
\item sim/tb\_design.v를 이번 TB 파일명으로 바꾼다.
\item constraints/pins.xdc를 이번 XDC 파일명으로 바꾼다.
\item 뒤의 코드 화면을 보며 작성하고 File → Save All.
\end{enumerate}
\end{frame}

\begin{frame}{openFPGALoader 설치}
\small
macOS에서는 Homebrew로 설치한다. Linux에서는 배포 패키지 또는 공식 설치 안내를 따른다.\par\terminalbox{brew install openfpgaloader}WSL은 USB JTAG 장치가 Linux 쪽에 전달되어 있어야 한다. 보드 전원·케이블·운영체제의 장치 인식을 먼저 확인한다.\par\href{https://trabucayre.github.io/openFPGALoader/guide/install.html}{공식 운영체제별 설치 안내}
\end{frame}

\begin{frame}{bit 읽기와 실제 기록}
\small
\terminalbox{bitread --part\_file "\$db/\$part/part.yaml" -C -z -y \textbackslash{}\\  -o build/cli/bits.txt build/cli/lab2\_integrated.bit\\openFPGALoader --list-cables\\openFPGALoader --detect\\openFPGALoader -c MY\_CABLE build/cli/lab2\_integrated.bit}MY\_CABLE은 실제 연결 케이블 식별자로 바꾼다. SRAM 기록이며 Flash 옵션 -f는 넣지 않는다.\par
\end{frame}

\begin{frame}{CLI 검증 범위}
\small
현재 S75 bit 생성·IDCODE·9,104프레임 읽기 결과는 예시의 evidence/openxc7에 있다.\par\vspace{0.26cm}nextpnr는 set\_false\_path를 무시한다. 이 예외는 Vivado 쪽 비동기 입력 타이밍 분석에만 적용된다.\par\vspace{0.26cm}파일 검사 성공은 실제 버튼·LCD·장치 프로그래밍 성공과 구분한다.\par
\end{frame}

\begin{frame}{장치에서 동작 확인}
\small
\begin{enumerate}
\item 보드 전원·JTAG·주 클록 1 kHz 설정을 확인한다.
\item 앞 장의 openFPGALoader --detect로 연결된 FPGA를 확인한다.
\item 실제 케이블 이름으로 MY\_CABLE을 바꾸고 방금 생성한 bit를 SRAM에 기록한다.
\item 종료 코드와 기록 로그를 확인한 뒤 리셋 버튼을 누른다.
\item 모드 버튼으로 8개 모드를 순회하며 LCD 이름과 회로 출력을 예상과 비교한다.
\end{enumerate}
\end{frame}
