\begin{frame}{PASS가 확인한 내용}
\small
리셋, 증가와 15→0 순환, 감소와 0→15 순환, enable=0 유지, 리셋 우선순위를 총 36회 검사한다.\par\vspace{0.26cm}이번 테스트벤치의 DUT는 counter4이다. 입력 동기화·디바운스와 실제 핀 동작까지 통과했다는 의미는 아니다.\par\vspace{0.26cm}편집기의 경고 4개는 남아 있다. 경고 0개로 기록하지 않는다.\par
\end{frame}

\begin{frame}{파형을 읽는 순서}
\small
\begin{enumerate}
\item clk 상승 에지 직후 value가 바뀌는지 본다.
\item down=0의 증가 구간과 down=1의 감소 구간을 비교한다.
\item enable=0 구간에서 value가 유지되는지 확대한다.
\item 마지막 rst=1 구간과 356 ns 종료를 확대해 확인한다.
\item 신호 이름·시간축·입력·출력이 함께 보이게 캡처한다.
\end{enumerate}
\end{frame}
