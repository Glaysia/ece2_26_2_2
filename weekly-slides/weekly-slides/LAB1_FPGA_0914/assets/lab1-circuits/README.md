# 실제 코드 화면

VS Code에서 최종 배포 RTL과 자기검사 TB를 열어 촬영했습니다. 새 코드 패널 52개는 입력·기대값·비교·종료, 통합 연결·버튼·LCD처럼 의미 단위로 나누었습니다. [기록](provenance.json)에 파일과 줄 범위, 원본·크롭·소스 해시를 남깁니다. 각 파일의 모든 줄이 패널에서 빠짐없이 한 번씩 포함되는지도 확인합니다.

이미지 편집은 원본 화면의 크롭만 수행했습니다. 긴 TB 문장은 VS Code의 자동 줄바꿈으로 표시했습니다. 코드 텍스트를 이미지 위에 다시 그리지 않습니다. PNG는 요청에 따라 새로 추적하지 않으며 완성 PDF에 포함됩니다.
