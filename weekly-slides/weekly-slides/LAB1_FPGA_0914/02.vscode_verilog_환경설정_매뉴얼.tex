\begin{frame}[fragile]{1. VS Code와 Git 설치}
\begin{itemize}
\item \href{https://code.visualstudio.com/docs/setup/windows}{VS Code Windows 설치 안내}에서 설치 프로그램을 받는다.

\begin{frame}[fragile]{1. 버전과 실행 경로 확인}

\begin{frame}[fragile]{5. 문법 오류를 확인하고 복원하기}

\end{itemize}\small 오류 위치가 다음 줄에 표시될 수도 있다. 경고도 내용을 읽고 원인을 확인한다.

\begin{frame}[fragile]{6. 전가산기의 예상 결과}

반가산기 두 개와 OR 연산을 연결한다.\par\vspace{0.3cm}

\end{column}
\end{columns}

\begin{frame}[fragile]{6. 테스트벤치는 무엇을 검사하는가?}
\begin{itemize}
\item \texttt{sim/tb\_full\_adder.sv}가 입력 000부터 111까지 인가한다.
\item 각 입력을 10 ns 동안 유지한다.
\item 입력 변경 1 ns 뒤 출력과 예상값을 비교한다.
\item 8개 입력을 모두 검사하고 총 80 ns에 종료한다.
\end{itemize}\checkline{1 ns는 시뮬레이션의 검사 대기 시간이다.}\par 실제 FPGA의 전파 지연을 측정한 값은 아니다.
\end{frame}

\item a, b, carry\_in, sum, carry\_out을 더블클릭하거나 +로 추가한다.
\item 파형 창에서 Zoom to Fit(Ctrl+0)으로 전체 구간을 본다.
\end{itemize}\source{https://marketplace.visualstudio.com/items?itemName=lramseyer.vaporview}{공식 안내: VaporView 신호 추가와 파형 조작}
