\begin{frame}{통합 테스트의 검사 범위}\relax
\small
10개 모드 × DIP 256개 = 2,560개 출력 비교.\par\vspace{0.22cm}reset → MODE 01, 짧은 바운스 무시, 길게 눌러도 한 번만 전환, 10→01 순환을 검사한다.\par\vspace{0.22cm}LCD 초기 명령과 외부 버스에서 완성된 두 줄의 번호·이름을 비교한다.\par\vspace{0.22cm}TB는 10ns 클록, 디바운스 4클록, 전원 대기 5클록으로 시간을 줄인다. 실제 합성은 1kHz 보드 설정이다.\par\vspace{0.22cm}XSim 검사 종료: 72430ns. 실제 보드의 전압·LCD 연결은 별도로 확인한다.\par

\begin{frame}{버튼을 길게 누르면}\relax
\small
2단 동기화 → 안정된 입력 20클록 확인 → 상승 시 1클록 펄스.\par\vspace{0.22cm}1kHz에서 약 20ms 안정 시간에 동기화 지연이 추가된다.\par\vspace{0.22cm}누른 채 유지하면 한 번만 바뀐다. 뗀 뒤 다시 눌러야 다음 모드가 된다.\par\vspace{0.22cm}모드 10 다음은 01. reset은 즉시 01로 돌아간다.\par\vspace{0.22cm}실험 영상에서 짧게 누르기·길게 누르기·순환을 각각 보여준다.\par
\end{frame}

\begin{frame}{LCD가 표시되는 과정}\relax
\small
전원 대기 50ms → 38,38,38,0C,06 초기 명령 → 두 줄 반복 갱신.\par\vspace{0.22cm}첫 줄 MODE 01…MODE 10, 두 번째 줄 회로 이름.\par\vspace{0.22cm}E high는 1ms, 바이트 간격은 최소 4ms. 첫 초기 명령 간격은 더 길다.\par\vspace{0.22cm}한 화면 시작 때 모드를 저장하여 두 줄이 다른 모드로 섞이지 않게 한다.\par\vspace{0.22cm}새 모드는 현재 전송을 마친 뒤 갱신되므로 잠깐 기다리고 읽는다.\par
\end{frame}
