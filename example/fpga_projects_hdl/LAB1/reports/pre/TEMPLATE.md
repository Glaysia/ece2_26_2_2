# 실험 전 레포트: 회로 번호·이름

작성자 / 작성일 / 소스 커밋 / workspace / OS / Python / 시뮬레이터 버전:

## 목적과 예상 동작

포트·비트 폭·비트 순서를 표로 정리합니다. 진리표 또는 연산 규칙과 정상·경계 입력의 예상 출력을 계산합니다. carry/borrow·MUX 순서·인코더 invalid 입력·7세그먼트 극성 중 해당 사항을 설명합니다.

## 소스와 테스트벤치

설계 top과 시뮬레이션 top, RTL·TB·XDC 링크를 남깁니다. 자극을 주는 순서, 각 입력의 유지 시간, 기대값 계산과 자동 비교, 검사 횟수, 종료·watchdog 조건을 설명합니다.

## VS Code 실행 과정

새 창 → workspace 선택 → 확장 → 저장 → Check tools → Simulate → Open waveform. 자신의 PASS 로그와 VCD·파형 캡처를 연결합니다. 오류가 있었다면 첫 오류, 수정, 재실행 결과를 구분합니다.

|---|---|---|---|---|
| 직접 측정하여 작성 | | | | |

전환 경계 대신 안정된 구간의 값을 읽고 최소한 정상·경계 조건을 비교합니다. PASS만 적지 말고 왜 그 출력이 나오는지 설명합니다.

## 코드 수정·실패·복구 실험

매뉴얼의 수정 과제를 수행합니다. 변경한 RTL 파일과 위치, 변경 전후 연산의 차이를 설명합니다. 테스트벤치 기대값은 유지하고, 실패를 예상하는 입력과 출력을 실행 전에 계산합니다.

## 보드 실험 계획

핀 제약과 입력·출력 장치를 연결하고 실험에서 확인할 조건, 촬영할 장면, 예상되는 차이를 적습니다. 이 단계에서는 Vivado GUI·실물 보드 결과를 수행한 것처럼 기록하지 않습니다.
