## Vivado 시뮬레이션 — Vivado 경로

프로젝트 생성·RTL/TB/XDC 등록과 두 top을 기록합니다. 자신의 PASS 로그·파형 캡처를 연결하고 사전 시뮬레이션과 입력·출력·시간·검사 수를 비교합니다.

## 오픈소스 실행 환경 — CLI 경로

Icarus 사전 시뮬레이션의 PASS·입력 해시·VCD를 연결합니다. Yosys·nextpnr·Project X-Ray·openFPGALoader 버전, 고정 DB 커밋, 패키지 핀 표 해시와 prepare_s75.py 결과를 기록합니다. 대상은 xc7s75fgga484-1입니다.

## 합성·구현·비트스트림

Vivado 경로는 합성·구현 결과를, CLI 경로는 Yosys → nextpnr → FASM → frames → bit 로그와 bitread 검사를 연결합니다. 각 단계 성공 상태, 이용률·DRC·타이밍 보고서, 경고·수정 내용을 정리합니다. bit 경로·파일 크기·SHA-256을 기록합니다. 조합회로의 timing NA는 통과 수치가 아닙니다.

## 실제 보드 기록·실측

연결된 장치와 기록 도구를 적습니다. Vivado 경로는 Program Device 완료 화면, CLI 경로는 실제 케이블·장치 탐색·openFPGALoader SRAM 기록 명령과 로그를 연결합니다. 두 경로 모두 배선·입력·출력이 함께 보이는 사진, 입력을 바꾸는 영상을 연결합니다.

## 비교·결론

Vivado 경로는 예상값 → VS Code → Vivado → 실측을 비교합니다. CLI 경로는 예상값 → Icarus → 오픈소스 구현 보고서 → 실측을 비교합니다. 구현 성공을 실물 동작 확인으로 대신하지 않습니다. 불일치가 있으면 코드·핀·극성·배선·타이밍 중 근거 있는 원인을 설명합니다. 미수행 항목은 명시합니다.
