# 실험 후 레포트: 회로 번호·이름

작성자 / 실험일 / 소스 커밋 / Vivado 버전 / part / top / XDC:

## Vivado 시뮬레이션

프로젝트 생성·RTL/TB/XDC 등록과 두 top을 기록합니다. 자신의 PASS 로그·파형 캡처를 연결하고 사전 시뮬레이션과 입력·출력·시간·검사 수를 비교합니다.

## 합성·구현·비트스트림

각 단계 성공 상태, 이용률·DRC·타이밍 보고서, 경고·수정 내용을 정리합니다. bit 경로·파일 크기·SHA-256을 기록합니다. 조합회로의 timing NA는 통과 수치가 아닙니다.

## 실제 보드 기록·실측

연결된 장치와 Program Device 완료 화면, 배선·입력·출력이 함께 보이는 사진, 입력을 바꾸는 영상을 연결합니다.

|---|---|---|---|---|
| 실제 수행 후 작성 | | | | |

통합본은 reset, 버튼 바운스·길게 누르기, 모드 01–10, 10→01, LCD 이름을 추가합니다.

## 비교·결론

예상값 → VS Code → Vivado → 실측을 비교합니다. 불일치가 있으면 코드·핀·극성·배선·타이밍 중 근거 있는 원인을 설명합니다. 미수행 항목은 명시합니다.
