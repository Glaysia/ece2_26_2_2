# 완성 예시 22개와 학생 템플릿

학생은 [빈 템플릿](https://github.com/Glaysia/fpga-lab-template/tree/v2.0.0)을 새 프로젝트 이름으로 clone하고 [직접 작성 순서](student-workflow.md)를 따른다. 아래 저장소는 완성 결과를 비교하는 참고 예시다. 각 저장소에 프로젝트 하나와 LAB1.code-workspace 하나가 있다.
