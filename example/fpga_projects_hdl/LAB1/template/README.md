# 학생 템플릿 위치

학생 템플릿은 [Glaysia/fpga-lab-template](https://github.com/Glaysia/fpga-lab-template/tree/v2.0.0) 한 곳에서 관리한다. 이 폴더의 예전 공통 workspace와 생성용 설정은 더 이상 사용하지 않는다.

```sh
git clone https://github.com/Glaysia/fpga-lab-template.git new_project_name
```

새 폴더의 `LAB1.code-workspace`를 열고 [직접 작성 순서](../docs/student-workflow.md)를 따른다. [완성 예시 22개](../docs/examples.md)는 각각 별도 저장소이며 강의 저장소의 서브모듈로 연결된다.
