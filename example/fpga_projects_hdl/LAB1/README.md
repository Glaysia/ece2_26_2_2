작성일 2026-09-10. 모든 프로젝트는 VS Code 사전 시뮬레이션과 실험 전 레포트부터 시작합니다. Vivado에서는 메뉴를 직접 눌러 시뮬레이션·합성·구현·bit 생성을 수행하고, 보드 기록·사진·영상은 실험 후 레포트에 넣습니다.

학생은 [빈 템플릿에서 직접 작성](docs/student-workflow.md)합니다. 완성 예시는 [22개 독립 저장소·서브모듈](docs/examples.md)로 구성되며, 각 폴더에 LAB1.code-workspace 하나가 있습니다. 최신 개별 10 + 최신 통합 1 + CLI 통합 1 + 레거시 10입니다. 아래 PDF와 Vivado 결과는 기존 배포 이력이며 새 템플릿 기준 PDF 개편은 진행 중입니다.
