# FPGA 예시 소스 찾기

[저장소 안내](../../README.md) · [LAB1](LAB1/README.md) · [LAB2](LAB2/README.md)

학생 실습은 [빈 템플릿 v2.0.0](https://github.com/Glaysia/fpga-lab-template/tree/v2.0.0)을 새 폴더로 clone한 뒤 매뉴얼을 보며 직접 작성한다. 아래는 강사용 예시 40개(LAB1 22개, LAB2 18개)다.

## GitHub에서 보기

서브모듈 폴더는 별도 저장소의 특정 커밋을 가리킨다. 아래 **소스** 링크로 해당 커밋의 RTL을 바로 열 수 있다. 부모 저장소의 Download ZIP에는 서브모듈 내부 파일이 포함되지 않으므로, 전체 예시가 필요하면 아래 clone 명령을 사용한다.

```powershell
git clone --branch main --recurse-submodules https://github.com/Glaysia/ece2_26_2_2.git
```

이미 clone한 저장소에서는 `git submodule update --init --recursive`를 실행한다. 이 명령은 부모 저장소가 기록한 커밋을 가져온다.
