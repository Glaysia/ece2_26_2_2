# LAB2 최종 배포 — 최신 Vivado 8 + 통합 Vivado 1

작성일: 2026-09-14 / 수업일: 2026-09-21

오늘 사용자 지시를 반영하여 CLI 매뉴얼을 제작·배포 범위에서 제외한다. 이전 GOAL0913_LAB2.md의 CLI 필수 조건과 10개/12개 배포 수량은 이 계획으로 대체한다. 기존 CLI 소스·PDF는 이력으로 보존한다.

배포 구성은 카운터, 클록 분주, 레지스터, 시프트 레지스터, PISO, Moore, Mealy, 7세그먼트 스캔과 버튼·LCD 통합 Vivado의 매뉴얼 9개다. 공통 예습과 전체 목차 2개를 더한 PDF 11개를 같은 폴더의 ZIP으로 배포한다.

- [x] 개별 8개 기존 PDF·TeX 해시가 전체 페이지 검수 기록과 일치함을 확인.
- [x] 생성·패키징 범위를 Vivado 9개로 변경.
- [x] 통합 Vivado 실제 GUI 프로젝트 생성, XSim, 핀 확인, 합성·구현·bit 생성 화면과 검증 기록 완성.
- [x] CLI 링크·학생 안내 제거, 공통 예습·목차 갱신.
- [x] 변경 PDF 전체 페이지 렌더 검수 및 기존 검수본과 비교.
- [x] PDF 내 목차·상대 PDF 링크 검증.
- [x] ZIP 생성 후 새 폴더에 압축 해제하여 구성·해시·링크 재검사.

학생 절차는 v2.0.1 빈 템플릿 clone → 직접 RTL/TB/XDC 작성 → VS Code Icarus 시뮬레이션 → 실험 전 레포트 → Vivado GUI → 비트스트림 → 실제 보드와 실험 후 레포트다. 실제 수행하지 않은 보드 기록·사진·영상은 수행했다고 표시하지 않는다.
