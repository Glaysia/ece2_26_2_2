# 2026-09-21 목표: LAB3 주변장치·UART 7개 완성

작성일 2026-09-21 / 수업일 2026-09-28

[OT의 LAB3 목록](../weekly-slides/weekly-slides/LAB0_OT_0907/03.LAB0_OT_0907.tex)과 기존 장비 예제를 기준으로 최신 Vivado 2026.1 실습 7개를 다시 작성한다. 화면 캡처는 코드·문서 원본과 검증이 끝난 뒤 별도 단계에서 수행한다.

공식 LAB3 제출 범위는 7개다. 통합 프로젝트와 오픈소스 CLI 프로젝트는 이번 범위에 자동으로 추가하지 않는다.

## 공통 설계 규칙

- 대상 장비: Combo II-DLD, Spartan-7 `xc7s75fgga484-1`, MAIN CLOCK F 50 MHz.
- 하나의 50 MHz 클록만 사용한다. 느린 동작은 카운터의 enable 조건으로 만든다.
- 외부 버튼·스위치·UART RX는 비동기 입력으로 취급한다. 버튼은 동기화·디바운스·원펄스를 거친다.
- 순차 블록은 비차단 대입을 사용한다. 일반 버튼을 `posedge button` 클록으로 사용하지 않는다.
- 보드용 시간 상수는 매개변수로 두고 TB에서는 작은 값으로 바꾼다.
- 기능 코어와 보드 top을 나누고, TB는 정상·경계 조건을 자동 비교한다.
- 실제 모터 회전·LED 밝기·음압·LCD 대비는 시뮬레이션만으로 검증했다고 쓰지 않는다.

## 학생 작업 흐름

1. `fpga-lab-template`의 `v2.0.2`를 새 프로젝트 이름으로 clone한다.
2. `src/`, `sim/`, `constraints/`의 파일을 교안을 보며 직접 작성한다.
3. VS Code의 01~03 작업으로 도구 확인, Icarus 시뮬레이션, VaporView 파형 확인을 수행한다.
4. 실험 전 보고서에 7개 전체의 요구사항·코드·자기검사 결과·파형 해석을 기록한다.
5. Vivado 2026.1 GUI에서 자신의 파일을 등록하고 XSim, 합성, 구현, bit 생성을 수행한다.
6. 당일 선정된 2개를 보드에서 시연한다. 실험 후 보고서에는 7개 전체 Vivado 파형과 선정된 2개 사진을 담는다.
